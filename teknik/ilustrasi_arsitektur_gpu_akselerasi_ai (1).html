Perbandingan Arsitektur: CPU vs GPU untuk AI

Arsitektur GPU Modern: CUDA Core vs Tensor Core

Pada GPU AI modern (seperti NVIDIA H100, A100, atau RTX 4090), terdapat dua jenis core utama: **CUDA Cores** (skalar/vektor umum) dan **Tensor Cores** (akselerator matriks khusus AI).

Standard CUDA Cores SIMT Architecture

Menjalankan **1 Operasi per Siklus Clock** per thread (misal: $A \times B + C$ pada skala skalar/vektor FP32).

Formula: Output = (a * b) + c (Multiply-Add skalar)
Kegunaan: Rendering grafis, estimasi awal, simulasi fisika, dan perhitungan matematika fleksibel umum.
Tensor Cores (AI Accelerator) MMA Hardware

Menjalankan **Perkalian Matriks $4 \times 4$ sekaligus dalam 1 Siklus Clock** (Matrix Multiply-Accumulate / MMA).

Formula: $D = A \times B + C$ (Perkalian Matriks FP16/BF16/FP8)
Kegunaan Khusus: Akselerasi drastis untuk **pelatihan & inferensi Transformer LLM** (hingga 16x lebih cepat dibanding CUDA core biasa).

Format Presisi Angka pada Pelatihan LLM (Precision Formats)

LLM dengan puluhan miliar parameter akan mengonsumsi VRAM memori yang sangat besar. Oleh karena itu, industri AI berpindah dari FP32 ke presisi campuran (**Mixed Precision FP16/BF16/FP8**).

FP32 (Single Precision)
Ukuran: 32 bit (4 Byte)
Sangat akurat, namun boros VRAM & bandwidth GPU. Digunakan untuk Master Weights Optimizer.
FP16 (Half Precision)
Ukuran: 16 bit (2 Byte)
Hemat VRAM 50%. Membutuhkan Loss Scaling agar nilai gradient sangat kecil tidak overflow/underflow.
BF16 (Bfloat16) ★ Standard LLM
Ukuran: 16 bit (2 Byte)
Range dinamis sama persis dengan FP32. Format standar paling stabil untuk training LLaMA, GPT-4, & DeepSeek.
FP8 / INT8 (Quantized)
Ukuran: 8 bit (1 Byte)
Paling hemat VRAM. Didukung Tensor Core GPU H100/Blackwell untuk inferensi cepat & ultra-large fine-tuning.

Mengapa 1 GPU Tidak Cukup? Multi-GPU Parallelism

Model LLM raksasa (seperti LLaMA-70B yang membutuhkan >140GB VRAM hanya untuk bobotnya) tidak muat dalam 1 GPU. Oleh karena itu, digunakan kombinasi 3 teknik **Parallelism** via interconnect super cepat seperti **NVLink & NVSwitch**.

1. Data Parallelism (DP/DDP)

Model LLM utuh diduplikasi ke semua GPU. Dataset batch besar dibagi rata. Setiap GPU menghitung gradient secara lokal, lalu menyinkronkan gradient via **All-Reduce**.

Cocok untuk: Model sedang yang muat di 1 VRAM GPU.
2. Tensor Parallelism (TP)

Matriks perkalian pada **tiap layer Transformer dipotong/dibagi** (column-wise / row-wise) ke beberapa GPU.

Cocok untuk: Mengatasi batas VRAM 1 GPU secara instan via NVLink.
3. Pipeline Parallelism (PP)

**Layer LLM dibagi secara sekuensial** antar GPU (misal: GPU 1 menangani Layer 1–20, GPU 2 menangani Layer 21–40, dst).

Cocok untuk: Skala cluster superkomputer raksasa.
